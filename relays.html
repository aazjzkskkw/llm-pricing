中转站

同一个模型能从四种地方买到，价格和风险差很多。同步时间：…
① 官方直营厂商自己的 API，定价即官网价看价格 →
② 官方认可的聚合平台有授权、能开票，自己定价但受厂商约束看规模 →
③ 第三方中转站把官方 API 或别人的反代聚合到自己手里再定价，多数基于 new-api / sub2api，通常比官方便宜
④ 公益站不能充钱，只有注册赠送和签到额度看名单 →
使用第三方中转前请注意：请求经由站点服务器转发，站方可读取、留存和修改传输内容； 实际调用的模型可能与所选型号不一致；服务与额度政策随时可能变更或终止。建议：
  1. 不传输代码仓库、密钥、客户资料等敏感内容；
  2. 不在第三方站点填入厂商官方 API Key；
  3. 接入前用无关内容试跑，核对返回的模型身份、流式行为与 token 计数；
  4. 生产环境使用厂商官方接口或下方官方免费额度。
